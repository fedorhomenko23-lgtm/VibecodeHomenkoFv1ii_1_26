1. Переменные и типы данных

Теория

Python — язык с динамической типизацией. Вам не нужно объявлять тип переменной, он определяется автоматически.

# Числа
age = 25
price = 19.99

# Строки
name = "Алексей"

# Логический тип
is_active = True

# Вывод в консоль
print("Привет,", name)
print(f"Вам {age} лет")

2. Условия (if/else)

Теория

Условные операторы позволяют выполнять код в зависимости от истинности выражения.

x = 10
if x > 0:
    print("Положительное")
elif x == 0:
    print("Ноль")
else:
    print("Отрицательное")

3. Циклы (for, while)

Теория

for используется для перебора элементов, while — для выполнения кода, пока условие истинно.

# Цикл for
for i in range(5):
    print(i) # 0 1 2 3 4

# Цикл while
count = 0
while count < 3:
    print("Итерация", count)
    count += 1

4. Списки и словари

Теория

list — упорядоченная изменяемая коллекция. dict — неупорядоченная коллекция пар ключ-значение.

fruits = ["яблоко", "банан", "вишня"]
fruits.append("груша")
print(fruits[0]) # яблоко

user = {"name": "Иван", "age": 30}
print(user["name"]) # Иван

6. Классы и объекты

Теория

Класс — это чертеж для создания объектов. Объект — это экземпляр класса.

class Car:
    def __init__(self, brand):
        self.brand = brand
    
    def honk(self):
        print(f"{self.brand} говорит: Би-бип!")

my_car = Car("Lada")
my_car.honk()

7. Исключения (try/except)

Теория

Блоки try/except позволяют перехватывать ошибки и не давать программе "падать".

try:
    x = int(input("Введите число: "))
    print(10 / x)
except ValueError:
    print("Это не число!")
except ZeroDivisionError:
    print("На ноль делить нельзя!")
